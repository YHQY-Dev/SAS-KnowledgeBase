怎么选模型

  • 接近等轴的胶体、胶束、囊泡 → 从 球 类开始。
  • 明显长径比（棒、管、盘）→ 圆柱；略扁/略长的旋转体或三轴体 → 椭球。
  • 脂质体、层状相、膜堆叠 → 层状。
  • 只需斜率、回转半径、分形维数或峰位，不关心具体外形 → 形状无关。
  • 浓溶液、相互作用峰或需把 $P(q)$ 与 $S(q)$ 分开讨论 → 加 结构因子。

更系统的选型思路见 学习路径 08。
